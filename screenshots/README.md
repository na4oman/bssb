# Screenshots Guide

This folder contains screenshots of the BSSB app for the README.md file.

## Required Screenshots

Please add the following screenshots to this folder:

1. **01-login.png** - Login/Authentication screen
2. **02-fixtures.png** - Fixtures tab showing upcoming matches
3. **03-events.png** - Events tab with upcoming events
4. **04-news.png** - News feed with posts
5. **05-table.png** - League table view
6. **06-hamburger-menu.png** - Hamburger menu showing admin options

## How to Take Screenshots

### For Android:
1. Run the app on your device or emulator
2. Navigate to each screen
3. Take screenshots using:
   - Physical device: Power + Volume Down
   - Emulator: Camera icon in the toolbar

### For iOS:
1. Run the app on your device or simulator
2. Navigate to each screen
3. Take screenshots using:
   - Physical device: Side button + Volume Up
   - Simulator: Cmd + S

## Image Guidelines

- Format: PNG
- Recommended size: 1080x2340 (or your device's native resolution)
- Keep file sizes reasonable (compress if needed)
- Ensure screenshots show the app in a good state (no errors, populated with data)

## After Adding Screenshots

Once you've added all screenshots to this folder, they will automatically appear in the main README.md file.
